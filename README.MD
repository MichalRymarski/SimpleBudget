# SimpleBudget

A very simple app that I made for my own personal use. 

## Live preview
[Github Pages](https://michalrymarski.github.io/SimpleBudget)

## Features:
- multiplatform (android is built, the rest is up to you)
- nice looking 😎
- allows you to create expense items and share them grouped by month, either by sharing everything or by sharing a single month
- captures payment notifications from GPay, Revolut and BLIK from ING (only in Polish, because making it work for all payments would require some kind of huge white list for payment keywords and black list for exceptions like bank promotions and all of that in all languages parsing every single notification)
